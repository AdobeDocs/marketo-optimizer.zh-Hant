# Adobe Marketo Optimizer檔案

[!DNL Adobe Marketo Optimizer]是AI優先的行銷自動化解決方案，可讓行銷人員和業務開發代表規劃方案、編排個人化個人歷程以及確認潛在客戶。 使用對話式AI，針對B2B銷售機會和帳戶個人化、AI支援的內容來建立及執行協調的行銷和銷售參與。
