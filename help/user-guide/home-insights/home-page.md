# 首頁

使用[!DNL Adobe Marketo Optimizer]中的[!UICONTROL 首頁]頁面來開始AI交談、啟動技能和開啟行銷工作區。 在導覽中選取&#x200B;**[!UICONTROL 首頁]**&#x200B;以返回此頁面。

個人化的歡迎訊息會詢問您目前任務的相關資訊。 選擇如何從對話輸入、意圖選項、快速存取卡片或技能卡片開始。

觀看首頁和行銷工作區導覽影片。 以下小節提供書面指示。

>[!VIDEO](https://video.tv.adobe.com/v/3505360/?quality=12&learn=on)

## 開始AI交談

使用[!UICONTROL 提出問題或開始工作]輸入以開始使用[!UICONTROL 同事]。 輸入`/`以瀏覽技能與命令。

1. 輸入問題或說明您要完成的工作。
1. 若要提供支援資料，請在輸入中選取&#x200B;**[!UICONTROL 附加]**&#x200B;並附加檔案。
1. 送出提示，以便在[!UICONTROL 同事]面板中繼續。

首頁也提供啟動工作的四個意圖選項。

| 選項 | 目標 |
| -------- | ------ |
| [!UICONTROL 計畫] | 規劃行銷活動。 |
| [!UICONTROL 建立] | 建立行銷內容或資源。 |
| [!UICONTROL 量值] | 檢閱行銷績效。 |
| [!UICONTROL 最佳化] | 調整現有的行銷活動。 |

如需詳細資訊，請閱讀[聊天介面](/help/user-guide/agents/chat-interface.md)。

## 快速存取

選取[!UICONTROL 快速存取]卡片以開啟工作區或檢閱AI決策健康狀態。

| 卡片 | 您可以存取的專案 |
| ------ | --------------------- |
| [AI-decisioning健康狀態](/help/user-guide/agents/ai-decisioning-health.md) | 故事數量和依角色分類的人員百分比。 |
| [行銷](/help/user-guide/marketing/marketing-management.md) | 行銷工作區中的方案、個人歷程和人員清單。 |
| [!UICONTROL 資產] | 電子郵件和頁面的內容資產。 |
| [!UICONTROL 報表] | 績效與參與報表。 |

## 技能

在[!UICONTROL 技能]中選取卡片以開始特定的AI工作流程。

| 技能 | 目標 |
| ------- | ------ |
| [!UICONTROL 建立角色型對象] | 使用角色訊號和固定配適度來產生對象。 |
| [!UICONTROL 建置全頻道程式] | 透過簡短的撰寫電子郵件、網頁和目的地的程式。 |
| [!UICONTROL 建立超個人化電子郵件] | 使用權杖和動態內容區塊來草稿個人化電子郵件。 |
| [!UICONTROL 符合度和意圖型歷程流量控制] | 使用帳戶符合度和意圖訊號在歷程間路由連絡人。 |

您也可以瀏覽[!UICONTROL 同事]的代理程式技能。 影片顯示[!UICONTROL 使用代理程式技能]對話方塊，其中包含搜尋欄位和類別篩選器。 如需詳細資訊，請閱讀[代理程式技能](/help/user-guide/agents/skills.md)。

## 導覽至工作區

使用應用程式導覽，從首頁或行銷工作區開啟下列工作區域。

| 工作區 | 您可以存取的專案 |
| ----------- | --------------------- |
| [!UICONTROL 行銷管理] | 計畫、個人歷程和人員清單。 |
| [!UICONTROL 歷程流量控制] | [歷程流量控制](/help/user-guide/marketing/journey-traffic-control.md)。 |
| [!UICONTROL 報表] | 行銷績效報表。 |
| [!UICONTROL 內容管理] | [!UICONTROL 範本]、[!UICONTROL Assets]、[!UICONTROL 片段]、[!UICONTROL Forms]、[!UICONTROL 登陸頁面]和[!UICONTROL 網路研討會]。 |
| [!UICONTROL 連線] | [目的地](/help/user-guide/audiences/destinations.md)。 |
| [!UICONTROL 實驗室] | [評分工作室](/help/user-guide/labs/scoring-studio.md)。 |
| [!UICONTROL 管理] | [!UICONTROL 頻道]和[!UICONTROL 程式型別]。 |

## 探索行銷工作區

在導覽中選取&#x200B;**[!UICONTROL 行銷]**&#x200B;快速存取卡或&#x200B;**[!UICONTROL 行銷管理]**&#x200B;以開啟行銷工作區。 使用[!UICONTROL 同事]、開啟行銷資源，並返回最近存取的專案，而不返回首頁。

1. 在&#x200B;**[!UICONTROL 行銷]**&#x200B;面板中選取&#x200B;**[!UICONTROL 方案]**、**[!UICONTROL 個人歷程]**&#x200B;或&#x200B;**[!UICONTROL 個人清單]**&#x200B;以瀏覽資源。
1. 選取要在工作區索引標籤中開啟的資源。 或者，在&#x200B;**[!UICONTROL 最近存取的]**&#x200B;中選取專案。
1. 若要繼續使用不同的資源，請在開啟的標籤之間切換。

[!UICONTROL 同事]面板會反映您開啟的資源。 其提示可針對選取的方案、人員清單或人員。 例如，開啟人員記錄會提供探索該人員角色和參與活動的提示。

選取&#x200B;**[!UICONTROL 摺疊]**&#x200B;以隱藏[!UICONTROL Co-worker]面板，或選取&#x200B;**[!UICONTROL 交換面板]**&#x200B;以變更其位置。 如需詳細資訊，請閱讀[行銷管理](/help/user-guide/marketing/marketing-management.md)和[人員詳細資料](/help/user-guide/audiences/person-details.md)。
